# PRO-FROST (PRObabilistic Forecast Risk Outlooks for Snow-related Thresholds)
This repository will house code for my NOAA Lapenta Project, which is a Random Forest based Probabilistic Snowfall Forecast Model, currently over the Northern Plains domain.

### Important Links.ipynb: 
This will host many of the major links to download GEFS-R atmospheric data, NOHRSC Gridded snowfall analysis, amongst other useful code such as concatenation of the 2-day GEFS-R data files into yearly files as well as one all-inclusive file. 

### Operational_GEFS_Download_links.ipynb:
Code to download and process future forecasted operational GEFS data, to use for the generation of daily outlooks.

### Auto_Daily_Outlooks.ipynb:
Code to produce daily outlook .png images using the Operational GEFS data.
